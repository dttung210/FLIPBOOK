# 📚 HƯỚNG DẪN SỬ DỤNG SÁCH LẬT TƯƠNG TÁC

## Cách sử dụng:

1. Upload toàn bộ thư mục này lên hosting hoặc chạy local server
2. Mở file index.html trong trình duyệt
3. Kéo thả hoặc chọn file PDF
4. Tùy chỉnh cài đặt và nhấn "Tạo Sách Lật"

## Chạy local server (Python):
```
python -m http.server 8000
```
Sau đó mở: http://localhost:8000

## Các chức năng:
- Hiệu ứng lật 3D
- Phóng to/thu nhỏ
- In và tải PDF
- Âm thanh lật trang
- Tìm kiếm nội dung
- Toàn màn hình
- Tự động lật trang

Chúc bạn sử dụng thành công! 🎉
